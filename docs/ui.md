# UI/UX Flows (Responsive)

## Global Navigation
- Role-based navigation menu.
- Clear call-to-action buttons for primary tasks.

## Admin
- Dashboard: total users, total courses, quick links to users/courses.
- Users list: search, filter by role, activate/deactivate.
- Courses list: view and manage publish status.

## Instructor
- Dashboard: courses created, enrolled students count.
- Course editor:
  - Course info (title, description)
  - Modules/lessons list with reorder
  - Content upload (PDF), video link, or text editor
  - Publish toggle
- Assignments: create, edit, view submissions, mark reviewed.

## Student
- Dashboard: enrolled courses, progress bar per course.
- Course view:
  - Modules/lessons list
  - Lesson content viewer
  - Mark lesson complete
- Assignments: submission form (text or file upload)
